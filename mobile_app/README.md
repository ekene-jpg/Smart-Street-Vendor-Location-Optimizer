# Smart Street-Vendor Location Optimizer — Flutter App

This folder contains the Dart source (`lib/`) and `pubspec.yaml` for the
mobile app. Flutter's native `android/`, `ios/`, etc. platform folders are
generated by the Flutter CLI on your machine (they contain machine/SDK
specific files that shouldn't be hand-written), so the first step below
creates them, then you drop this source in.

## 1. Prerequisites

Install the Flutter SDK: https://docs.flutter.dev/get-started/install
Then verify:

```bash
flutter doctor
```

## 2. Set up the project

```bash
flutter create --org com.smartvendor --project-name smart_vendor_app smart_vendor_app_project
cd smart_vendor_app_project
# Replace the generated lib/ and pubspec.yaml with the ones from this package:
rm -rf lib
cp -r /path/to/mobile_app/lib .
cp /path/to/mobile_app/pubspec.yaml .
flutter pub get
```

## 3. Point the app at your backend

Edit `lib/config.dart`, or pass it at build/run time:

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:4000/api        # Android emulator -> local backend
flutter run --dart-define=API_BASE_URL=https://your-app.onrender.com/api  # deployed backend
```

## 4. Run in development

```bash
flutter run
```

## 5. Build release packages ("ready for deployment")

```bash
# Android App Bundle (for Play Store)
flutter build appbundle --dart-define=API_BASE_URL=https://your-app.onrender.com/api

# Android APK (for direct install/testing)
flutter build apk --release --dart-define=API_BASE_URL=https://your-app.onrender.com/api

# iOS (requires a Mac + Xcode + Apple Developer account)
flutter build ipa --dart-define=API_BASE_URL=https://your-app.onrender.com/api
```

Outputs land in `build/app/outputs/...` (Android) or `build/ios/ipa/` (iOS).

## App structure

```
lib/
  main.dart                 # app entry, theme, providers
  config.dart                # API base URL
  models/                    # Location, User
  services/
    api_service.dart         # all HTTP calls + JWT token storage
    app_state.dart            # logged-in user state (Provider)
  screens/
    login_screen.dart
    register_screen.dart
    home_map_screen.dart       # OpenStreetMap map with candidate-location markers
    preferences_screen.dart     # adjust suitability weights (Ch.3 formula)
    results_screen.dart          # ranked recommendation list
    location_detail_screen.dart   # feature breakdown for one location
```

Uses `flutter_map` (OpenStreetMap tiles) instead of Google Maps, so no API
key/billing setup is required to run or deploy.
